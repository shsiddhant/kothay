# Changelog

## [0.1.0] - 2026-11-25

### Added

- Initial release of `kothay`.
- `tag` command to attach repeatable or comma-separated tags to files and directories.
- `untag` command to remove specific tags or clear all tags (`--all`) from paths.
- `find` command to search tagged resources by tag segments, with `--files` and `--dirs` filters.
- `ls` command to inspect tags for a specific path or list all tags in the database.
- `version` command and `--version` flag with build metadata injection.
